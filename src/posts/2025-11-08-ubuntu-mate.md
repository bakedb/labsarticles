## Day 1
I broke Xubuntu, so now I'm here. Xfce will be pretty difficult to top, so we'll see if MATE can do it. So far, everything that has gone wrong has been my fault, most of which was accidentally deleting most of the stuff on the top menu bar. Luckily, they must have predicted that someone like me would be messing around in their desktop environment, so they included a useful reset button. How generous. MATE has been really similar to Xfce, with slight differences in the menu styles looking more like modern GNOME and icons looking more flat. If you aren't a diehard fan of flat design but don't like the older look of Xfce, MATE is right for you.

![Ubuntu MATE](https://github.com/bakedb/distro-tests/blob/master/Review%20Logs/ubuntu-mate/screenshot-0.png?raw=true)

One problem that I have is not being able to easily change the clock from 12-hour format to 24-hour. You have to use the command ```gsettings set org.gnome.desktop.interface clock-format '24h'```. I don't know why that isn't an easily accessible option, but this does just as good of a job.

I am glad that MATE does not have the same lid-closing problem that Xfce did, and that will definity put it in the lead for best DE. The only things that Xfce has going for it is the visual style (in my opinion) and the fact that it autocompletes paths and application names when creating a Launcher on the desktop.

I think that the less than one day I spent with Xubuntu didn't really give me the full experience, so I will try to go as close to a week with each distro as I can. I might also have one on my desktop, too.

Another thing that I do not like about MATE is the App Center flashing out of control when I move my cursor while it is open. It is still completely usable, but quite annoying.

Ok, nevermind. It's all good now. Maybe I just had to refocus the window or something.

## Day 2
Some of the preinstalled software here includes a camera, backup utility, document scanner, the LibreOffice suite, magnifier, dictionary, calculator, and one thing that I remember from when I used Raspberry Pi OS: the Plank application. It gives you a macOS-like dock on your desktop, and I am surprised that it came preinstalled by default.

![Plank application and configuration window](https://github.com/bakedb/distro-tests/blob/master/Review%20Logs/ubuntu-mate/screenshot-1.png?raw=true)
> In this image, I have one of the default panels at the bottom of the screen, so the dock is a bit higher up than one might want.

Another thing that I have noticed is that when I want to put an application launcher on the bottom panel, there is a gap between the launcers and the list of open windows that I cannot seem to get rid of. It's not that much of a problem, but it is a little bit irritating.

![Bottom panel with gap](https://github.com/bakedb/distro-tests/blob/master/Review%20Logs/ubuntu-mate/screenshot-2.png?raw=true)

One thing that I like about MATE that Xfce did not have is the ability to touch my trackpad instead of having to press it down or use the buttons above it. I don't know why it didn't work before, but I'm glad that it does. So far, I would definitely say that MATE is above Xfce.

## Day 3
I think I have seen enough of Ubuntu MATE, so I will be switching today. This has been the best desktop environment so far, but I have only been trying Ubuntu-based systems. Next, I'll be trying something different. Anyway, MATE has checked all of the boxes for me, and it didn't seem to have any visible bugs that would be dealbreakers like there were in Xfce. 9/10.
